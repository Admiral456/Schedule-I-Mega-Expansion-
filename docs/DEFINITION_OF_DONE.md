# Definition of Done

A province, shop, NPC, business or system is not complete merely because it renders.

## Province
Geometry, collision, entrances, safe road connection, navigation (or documented limitation), stable IDs, host/client parity, save/load and performance budget.

## Shop
Physical and phone UI work; shared stock/prices; atomic idempotent purchase; pickup/delivery persists; client and host agree after reconnect.

## Business
Listing appears in Realtor; host-authoritative purchase; ownership persists; connection to employee/stock/finance/reputation; rollback exists.

## NPC
Stable ID, profile, schedule; preferences change behavior; contact in Hyland Network; optional orders/contracts; reputation changes once.

## Hyland Network
Phone UI, persistent data, schema validation, permission checks, host/client sync and reconnect; no duplicate order/message/payment/reward.

## Release
Clean install, pinned versions, no secrets/game binaries/proprietary assets/saves, known limitations and changelog. A feature is not done merely because it renders.
