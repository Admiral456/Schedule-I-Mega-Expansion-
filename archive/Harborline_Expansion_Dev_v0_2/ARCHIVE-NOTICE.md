# Historical source archive – v0.2

This is the source from the earlier Harborline visual greybox prototype. It is preserved for reference only. It is not the source for the 0.3.1 gameplay DLL and must not be built/deployed as the current mod. Its Enabled=false default is intentional. It uses a Mono S1MAPI compile reference and only spawns prototype geometry after an explicitly enabled test configuration.
