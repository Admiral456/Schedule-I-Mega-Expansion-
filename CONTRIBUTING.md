# Contributing

- Preserve the three-province scope: Harborline, Ridgeview, Lakeside.
- Do not claim compatibility without tested game build, runtime, versions and test notes.
- Every gameplay entity needs stable IDs and save/network consideration.
- Every new purchasable business must integrate with Realtor.
- Customer/order systems must integrate with Hyland Network.
- Online and physical shop share stock and prices.
- Every shared feature defines host authority and late-join behavior.
- Test on a copy of the save.

PR checklist: requirements, stable IDs, schemas, migrations, multiplayer, host/client, save/load, late join, asset license, no game files or saves in repository.
